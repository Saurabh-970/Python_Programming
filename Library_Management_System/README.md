# 📚 Library Management System (Python)

A menu-driven **Library Management System** built using **Python** and **Object-Oriented Programming (OOP)** principles. The project allows users to manage books in a library with features like adding, searching, issuing, returning, and removing books. All data is stored in a **JSON file**, so the library is preserved even after the application is closed.

---

## 🚀 Features

* ➕ Add a new book
* 📖 Display all books
* 🔍 Search books by ID
* 🔎 Search books by name
* 📕 Issue a book to a borrower
* 📗 Return an issued book
* 🗑️ Remove a book
* 💾 Automatic data saving using JSON
* 📂 Automatic data loading on startup
* ✅ Duplicate Book ID validation
* ✅ Input validation and exception handling
