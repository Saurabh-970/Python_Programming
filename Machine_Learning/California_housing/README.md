# 🏡 California Housing Case Study

This project focuses on predicting California housing prices using various **Machine Learning Regression Techniques** and Ensemble Learning methods.

## 📌 Algorithms Used

### 🔹 Individual Regression Models

* Linear Regression
* Decision Tree Regression
* Random Forest Regression

### 🔹 Bagging Techniques

* Bagging Regressor
* Ensemble Learning Methods

### 🔹 Boosting Techniques

#### Regression

* AdaBoost Regression
* Gradient Boosting Regression
* XGBoost Regression

#### Classification

* AdaBoost Classifier
* Gradient Boosting Classifier

To compare the performance of different regression and ensemble learning algorithms on the California Housing dataset and understand how boosting and bagging improve prediction accuracy.
