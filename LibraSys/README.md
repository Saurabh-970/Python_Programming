# 📚 LibraSys

> **A Modern Library Management System built with Python, Object-Oriented Programming (OOP), JSON, and Streamlit.**

LibraSys is a user-friendly Library Management System that allows users to manage books, issue and return books, search books, and maintain records through a clean graphical interface built using **Streamlit**.

---

## 🚀 Features

- 📖 Add New Books
- 📚 View All Books
- 🔍 Search Books (By ID & Name)
- 📤 Issue Books
- 📥 Return Books
- 🗑 Remove Books
- 💾 JSON-based Data Storage
- 📊 Dashboard with Statistics
- 🥧 Pie Chart Visualization
- 📥 Export Library Data as CSV
- 🎨 Modern Streamlit GUI
- 📈 Real-time Library Analytics

---

## 🛠 Tech Stack

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/LibraSys.git
```

---

### 2️⃣ Go to Project Folder

```bash
cd LibraSys
```

---

### 3️⃣ Install Dependencies

```bash
pip install streamlit pandas plotly
```

or

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

Open Terminal inside the project folder.

Run

```bash
py -m streamlit run app.py
```

or

```bash
streamlit run app.py
```

The application will automatically open in your browser.

---

## 💾 Data Storage
